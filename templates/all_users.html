User Deletion & Admin Rights
Deleting a student

Deleting a student fully deletes all data related to the students. This includes but is not limited to: username, email, password, activity timestamps, enrollments, task submissions, move history, and time spent on tasks. This also removes all their attempt data from global statistics.

Promoting a teacher (Make Admin)

Promoting a teacher grants them full admin rights. This action is not reversible and the promoted teacher account cannot be deleted anymore. Please make sure you select the correct account before confirming.

Deleting a teacher

Deleting a teacher deletes all private data of the teacher. This includes but is not limited to: username, email, password, activity timestamps, and private tasks.

All public tasks and task sets change ownership to a user made for deleted accounts (deleted_user). Public tasks stay fully accessible for everybody, their creator ID just changes.

Task sets are automatically closed and their URL is deleted. Private tasks in task sets are removed. All other task set data is kept. This allows admins to look at any students and submissions in the task set. This also allows the global statistics to not be affected by deleted teacher users.
