Create a New Task

Write plain Python in the first editor and any Python test code in the second editor. You can use assert, loops, helper functions, and multiple test cases.

Step-by-Step Guide

  1. Write the Task Function

    In the Task Code editor, write a Python function that defines the task students need to solve.

  2. Create Test Cases

    In the Task Tests editor, write tests that verify the function works correctly. Use assert statements for clear checks.

  3. Continue to Block Builder

    When you're ready, click "Continue To Block Builder" to set up the scrambled code blocks for students. You can add more code blocks in Block Builder as needed. To create a faded editable block, type !BLANK in a custom block (for example total = !BLANK).

Example Task: Format Names

Here's a complete example:

Task Code 
def format_name(first, last):
    return f"{first.strip().title()} {last.strip().title()}"
Task Tests 
assert format_name('ada', 'lovelace') == 'Ada Lovelace'
assert format_name('  linus', 'torvalds ') == 'Linus Torvalds'
