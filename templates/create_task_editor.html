Create Task Blocks

Match the student problem style while building code blocks. Add from source lines or create custom blocks below.

  1. Drag only the blocks that should be in the model answer to the right column. Leave distractors on the left.
  2. Use + Add Custom Block to add a new custom code block.
  3. Write or verify tests in the Tests area and click Run Tests before saving.
  4. Click Set as Model Answer. You can click it again later to update the saved model answer.
  5. Click Preview to review the block page.
  6. When all tests pass, click Add to Problem List to publish the task.
