Create Task Blocks

Match the student problem style while building code blocks. Add from source lines or create custom blocks below.

  1. Drag only the blocks that should be in the model answer to the right column. Leave distractors on the left.
  2. Optionally double-click any right-column block to pin it as pre-given for students — it will start in their solution area. Pinned blocks show a blue pin (📌) and blue highlight.
  3. Use + Add Custom Block to add a new custom code block.
  4. Write or verify tests in the Tests area and click Run Tests before saving.
  5. Click Set as Model Answer. You can click it again later to update the saved model answer.
  6. Click Preview to review the block page.
  7. The Make task private checkbox is off by default (leaving the task public, which is preferred to help the community). Public tasks remain in the system for other teachers even if your account is removed. Check this box to make the task private.
  8. When a task is private, only the creator can see it, plus teachers who have access to a task set that includes the task.
  9. When all tests pass, click Save Task to Problem List to publish the task with the selected visibility.
