Data Retention Policy

Last updated: July 9, 2026

Purpose

This policy defines how long Parsons Code Lab retains personal data and educational records in accordance with the principles of data minimization and storage limitation under the GDPR.

Teacher Accounts

Teacher account information is retained while the account remains active.

When a teacher account is permanently deleted, all associated personal information is removed.

Student Accounts

Student account information is retained while the student uses the platform.

If a student account is deleted, all associated educational records and personal information are removed.

Learning Records

The following educational records are retained while the associated student account exists:

  • Task enrollments
  • Task attempts
  • Task sessions
  • Move events
  • Edit events

These records are necessary to display student progress and allow teachers to review completed work.

Registration Tokens

Unused registration tokens may be periodically removed once they are no longer required.

Expired Task Sets

Expired task sets remain stored until removed by a system administrator.

Backups

Database backups are retained only for operational recovery purposes and are automatically removed after 14 days.

Account Deletion

When an account is permanently deleted:

  • Personal account information is deleted.
  • Educational records linked to the account are deleted through cascading database relationships.
  • Any remaining backup copies are removed according to the backup retention schedule.

Policy Review

This policy should be reviewed whenever significant changes are made to the application's data model or data processing practices.
