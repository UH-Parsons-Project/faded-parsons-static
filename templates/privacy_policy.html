Privacy Policy

Last updated: July 9, 2026

1. Introduction

Parsons Code Lab is an educational web application designed to help students practice programming using Parsons Problems. This Privacy Policy explains what personal data we collect, why we collect it, how we protect it, and the rights users have under the General Data Protection Regulation (GDPR).

2. Data Controller

For this project, the data controller is the operator of Parsons Code Lab. For questions regarding privacy or personal data, please contact the system administrator.

3. Personal Data We Collect

Teacher accounts

We collect:

  • Username
  • Email address
  • Password hash
  • Account creation and update timestamps
  • Account status

Student accounts

We collect:

  • Username
  • Email address
  • Password hash
  • Account creation and update timestamps
  • Account status
  • First activity timestamp
  • Last activity timestamp

Learning activity

To provide the educational functionality of the platform, we record:

  • Task set enrollments
  • Task attempts
  • Task completion status
  • Code block movement events
  • Code editing events
  • Session start and end times

These records are associated with the student's account.

4. Why We Process Personal Data

We process personal data in order to:

  • Authenticate users.
  • Manage teacher and student accounts.
  • Deliver programming exercises.
  • Record student progress.
  • Allow teachers to review student work.
  • Improve the educational experience.
  • Maintain system security.

We do not use personal data for advertising or marketing.

5. Sharing Personal Data

Personal data is not sold or shared with third parties for commercial purposes. Authorized teachers may view data relating to students enrolled in their task sets. System administrators may access personal data when necessary for maintenance, security, or troubleshooting.

6. Data Retention

Personal data is retained only for as long as necessary to provide the educational service and for the periods described in the Data Retention Policy. Users may request deletion of their accounts where applicable.

7. Cookies

Parsons Code Lab uses only cookies that are necessary for authentication and operation of the application. If optional analytics cookies are introduced in the future, users will be asked for consent before they are used.

8. Changes to this Policy

This Privacy Policy may be updated to reflect changes to the application or applicable legislation. The latest version will always be available within the application.
